## Build a new candidate
Use Windows x64 for this build/test gate, which retains native Windows Skia tests. The deployed application runs in supported browsers from a static folder. No .NET runtime, Node, sibling checkout, package feed or database is needed on the static host.

Install the exact SDK and Node versions, then run from the app directory:

```powershell
dotnet workload install wasm-tools --skip-manifest-update
./scripts/build.ps1 -Output artifacts/candidate-root
# Or select a hosting subpath before packaging:
./scripts/build.ps1 -Output artifacts/candidate-draw -BasePath /draw/
```

The output directory must be absent. `-PackagesPath` can select a new isolated directory; otherwise the script uses `artifacts/packages`. Existing artifacts are never overwritten. Source verification runs before restore. The script locked-restores, rechecks the resolved native toolchain, audits package cache contents, builds the solution and all nineteen sibling projects in Release, requires nonzero/all-passed C# test counters, runs all JavaScript tests, native-links a trimmed publish, verifies/finalizes assets, records provenance, packages `wwwroot` and compares every ZIP entry with the verified folder. A failure stops subsequent steps; retained logs identify the failed gate.

The four multi-target Beep projects accept the explicit `BeepSkiaPortableTargetFramework=net10.0` build property. Their ordinary net8/net9/net10 lists remain the default for other callers. The solution lists those same four projects so Release configuration maps correctly. Do not globally set `TargetFramework` or `TargetFrameworks` across single-target app projects: the former can create two MSBuild instances writing the same output; the latter can generate conditional NuGet imports that omit native Skia, test adapters and offline assets. Restore metadata is removed from runtime content. `BeepSkiaLocalBuildCopies=false` disables machine-local DLL/package copy targets for this build; other consumers keep their defaults.

Managed compilation runs before tests; the deployment's native WASM is linked during publish. The intermediate managed build's browser folder is not the release payload. Use the verified `publish/wwwroot` or `simpledraw-static.zip`.

## Candidate contents and integrity

Builds verify `dependencies/notices/inputs.lock.json`, full original vendor texts and the generated public `licenses/` bundle before restore. After publish, `runtime-notices.json` maps every actual framework/content/font identity file to exact resolved package, SDK or reviewed source inputs and notice groups. All 24 notice files must have their exact offline SRI entries. Unknown payload sources, changed original notices or changed licensed font bytes stop packaging. This report and the notice-input digest are pinned in provenance. See [notice verification](P6_NOTICES_VERIFICATION.md) for capture/update procedure, conservative vendor collection scope and unsigned owner/header review.
`asset-report.json` records each identity file hash, identity/Brotli/gzip sizes, offline version, base path and the artifact's CSP. The whole-folder Brotli inventory must be at most 25 MiB; this is an inventory gate, not an observed cold network transfer. `provenance.json` records app source hashes, sibling source digest, exact input/toolchain/package hashes and the asset report hash. Logs and C# TRX results accompany the archive. ZIP entry checks and `.sha256` protect the delivered archive. Input reproducibility is verified; byte-identical ZIP files across machines are not claimed.

Base path must be `/` or slash-terminated ASCII segments such as `/draw/`. Finalization verifies the SDK's original offline payload first, changes the entry base/hash, derives a content version and regenerates the changed encodings. It also regenerates the SDK's final copied `service-worker.js` encodings. Other mismatched payloads or encodings fail. Import-map/preload integrity, required font/license, native WASM, safe/unique relative URLs and absence of external entry resources are checked. The verifier cannot by itself prove the running browser makes no external requests; that is a browser/network gate.
